FBR Compliance 2026 Info

This application implements real-time digital invoice uploading to FBR using DI API V1.12 specifications.

Rules Applied:
  • Standard Sales Tax computed.
  • Further Tax (4%) applied to Unregistered Buyers.
  • Receipt QR code sized exactly 1" x 1" (v2.0, 25x25).

Sandbox testing mode allows using 28 scenarios (SN001-SN028) to test diverse supply chain transactions.
